# docs/incidents/ —— 事故账

一次静默失效一页。**门槛只有一条:这一页必须答得出「防复发:哪个门禁守着它」,
并且那个门禁对出事那版代码是红的。** 答不出就别建页 —— 一页没有门禁的事故记录,
下一次照样复发,只是这次有人写过而已。

每页的形状:现象 → 根因 → 修法 → 防复发(门禁路径 + 怎么跑 + 对旧代码为什么是红的)。

## 不属于这里的东西

- **项目事实与部署要求**(比如某个入口的鉴权在仓外)→ README 或部署文档
- **待拍板的决定**(比如某个死端点删不删)→ issue 或提交说明,别写成事故
- **别的仓库的坑**、**本机环境状态**(凭据、账号、路径)→ 不进这个仓
- **设计参照与选型偏好** → PRD

判据是「一份干净 clone 里,下一个人能不能照着它避开同一个坑」。避不开的,
说明缺的不是这一页,是门禁。
