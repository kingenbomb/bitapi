A FEW GOOD QUESTIONS

开始之前。

可以继续使用现有的 SDK 吗？+

可以。使用 OpenAI 或 Anthropic SDK 时，替换 base_url、API 密钥和模型名称即可。具体功能支持以模型广场展示的能力为准。

需要登录才能看模型和价格吗？+

不需要。访客可以直接进入模型广场，查看默认分组的模型与价格。登录后会展示你所在分组的实际可用范围和定价。

调用费用如何查看？+

按 Token 计费的模型以美元 / 1M token 展示，部分渠道按次计费。实际消费取决于模型、分组倍率与计费策略，可在控制台的使用记录中查看。
